### How to link a file on the website:
In `index.html`, simply update the link in the corresponding conference item:
```html
<a href="materials/2026-sheffield-abstract.pdf" target="_blank" class="material-pill active">Abstract (PDF) ↗</a>
```
The button will automatically turn green/active and open the file directly in the visitor's browser!
